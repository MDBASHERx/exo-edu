# 🎓 EXO Education

Modern educational and attendance management platform designed for academies, schools, and online learning environments.

Built to simplify student management, attendance tracking, scheduling, and online class integration.

---

# ✨ Features

- Student attendance tracking
- Academy & classroom management
- Zoom meeting integration
- Course scheduling system
- Student dashboard
- Lecturer dashboard
- Authentication & permissions
- Responsive modern UI
- Multi-role system
- Statistics & analytics
